# シャドーイング専用プレーヤー

動画と日英SRT字幕を使ったシャドーイング練習用 Android アプリです。

## 機能

- 動画ファイル（mp4 等）を端末から選択
- 日本語・英語の SRT 字幕ファイルを個別に読み込み
- 動画内のテキスト字幕を全件読み込み、SRT と同じ字幕リストとして表示
- 字幕ボタンから内部字幕または外部SRTを選択
- **前へ / 次へ** で英語字幕の開始時刻へ自動シーク
- **▶ 再生** で英語字幕区間だけを再生（終了時に自動停止）
- 動画上の操作ボタンを非表示にし、通常再生は下部ボタンで操作
- 動画下の字幕領域を横スワイプで英語・翻訳切り替え
  （時刻で自動選択。**対応なし**の英語行は明示）
- 字幕領域の横に細い現在位置バーを表示
- 現在位置バーは左右を切り替え可能
- **英語・日本語それぞれ** タイミングを ±0.1s / ±0.5s でずらせる（再生は英語基準）

## 必要環境

- Android Studio（AGP 9.2.1 対応版）
- JDK 17
- Android SDK 36

## ビルド手順

1. Android Studio で `shadowing-app` フォルダを開く
2. Gradle Sync を実行
3. 実機またはエミュレータで Run

```powershell
cd shadowing-app
.\gradlew.bat assembleDebug
.\gradlew.bat :app:testDebugUnitTest
```

`gradlew.bat` はプロジェクト同梱の Gradle Wrapper です。PC に Gradle を別途入れなくても、同じバージョンでビルド・単体テストが実行できます。

## 使い方

1. **動画** ボタンで動画ファイルを選択
2. **英語SRT** / **翻訳SRT** で字幕ソースを選択
   - 内部字幕がある場合 … 内部字幕または外部SRTを選択
   - 内部字幕がない場合 … 内部字幕は無効表示、外部SRTを選択
3. 動画下の字幕欄を横スワイプして英語・翻訳を切り替える:
   - **動画を再生** … 動画を現在位置から通常再生
   - ◀ **前へ** / **次へ** ▶ … 英語字幕ブロック単位でシーク
   - ▶ **再生** … 英語ブロックの開始〜終了だけを再生
   - 右側の現在位置バー … 動画内の現在位置を表示
   - スライダー位置 … **設定** 画面で左右を切り替え
   - 字幕欄を上下スクロール … 中央付近の字幕へすぐシークして再生
4. **タイミング調整** で英語・日本語を個別にずらす（ずれ補正用）

## SRT 形式

標準的な SubRip 形式に対応しています。

```
1
00:00:01,000 --> 00:00:04,000
こんにちは

2
00:00:04,500 --> 00:00:08,000
Hello
```

## 注意

- 日英で **行数・分割が違ってもOK**
- 内部字幕は読み取れたテキスト字幕のみ SRT と同じ操作に対応します
- 対応判定: 重なりありは表示、区間の隙間が 1.0 秒以内は不明確、1.0 秒を超える隙間は対応なし
- **シーク・リピートは英語 SRT**（＋英語オフセット）を基準
- 日本語オフセットで日本語側の時刻をずらし、マッチする行が変わる
- ファイルは Storage Access Framework 経由で読み込みます

## リリース準備（v1.6.1）

- **設定画面**: 起動時セッション復元 ON/OFF、初期再生速度、初期スライダー位置
- **初回ガイド**: 初回起動時に使い方ダイアログ（設定から再表示可）
- **法的情報**: プライバシーポリシー・利用規約をアプリ内表示（設定 → 法的情報）
- **クラッシュレポート**: Firebase Crashlytics（ビルド前に本番用 `app/google-services.json` を配置。ファイルは Git 管理外）
- **広告**: 画面上部に AdMob バナー（本番 ID 設定済み）
- **開発者向け（デバッグビルドのみ）**: 設定から広告の表示/非表示を切り替え可能

`strings.xml` の `legal_contact_email` には公開用の問い合わせ先を設定済みです。

## 作品ごとの設定（最大30件）

動画 URI ごとに次を記憶します（古い作品から自動削除）。

- 英語・日本語のタイミングオフセット
- 外部 SRT の URI（読める場合のみ再読み込み）
- 再生速度・シークスライダー左右

「起動時セッション復元」は**直近1回分の再生位置**用、作品リストは**複数作品を行き来するとき**用です。

| ファイル | 用途 |

| `docs/privacy-policy.html` | **Play に登録する URL** |
| `docs/terms-of-service.html` | 利用規約（任意） |
| `docs/README.md` | GitHub Pages の公開手順 |

**登録 URL**（[medio-core/shadowing-app](https://github.com/medio-core/shadowing-app)・GitHub Pages・`docs` 公開時）:

```
https://medio-core.github.io/shadowing-app/privacy-policy.html
```

手順: リポジトリを GitHub に push → Settings → Pages → Branch `main`、Folder **`/docs`** → 数分後に URL 確認 → Play Console の「プライバシーポリシー」欄に貼る。

## Play 本番公開（概要）

1. ダッシュボードの必須タスク（ストア掲載情報・データ セーフティ・レーティング・広告あり 等）を完了
2. 上記 **プライバシーポリシー URL** を登録
3. **製品版**に署名付き AAB（v1.6.1 / versionCode 129）をアップロード
4. リリースノートを書いて **審査に提出** → 承認後に段階的または一括公開

詳細は会話ログまたは Play Console のガイドを参照してください。
